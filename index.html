Visualizing how heat eventually redistribute and come to an equilibrium after some time, with initial heat function and initial condition.

Tech stack: Numpy, Sympy, Matplotlib

Result: A small Python app demonstrating heat distribution of a metal rod over time using Crank-Nicolson numerical method.

NYC Motor Vehicle Collisions - Severity Prediction

Exploratory data analysis and a from-scratch attempt at predicting whether a motor vehicle collision in New York City resulted in an injury or fatality, using the NYC Open Data "Motor Vehicle Collisions - Crashes" dataset (~2.27M rows).

Tech stack: Numpy, Pandas, Scikit-learn

Result: Severity turns out to be a genuinely hard target to predict from crash-level metadata alone (time, location, vehicle type, contributing factor). The best model reached F1 ≈ 0.49, Accuracy ≈ 0.7 on the positive (injury/fatal) class after feature engineering, imbalance handling, and hyperparameter search.

ASCII Image/Text Generator

Upload a picture, get back a colored ASCII-art rendering of it. Under the hood it is an asynchronous, queue-based backend: the API never does the heavy image work itself. It stores the upload, records a job, and hands the work to a separate worker process.

Tech stack: TypeScript Fastify, TypeBox, BullMQ on Redis, PostgreSQL, Prisma, React, Cloudflare R2, AWS EC2

Result: A completed app, ready to be delployed on Cloud Instances.
